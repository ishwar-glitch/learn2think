# Learn2Think — Style & Quality Guide (v4)

## 1. Voice
- Write like a sharp senior colleague: direct, warm, never academic.
- Speak to the learner as "you". Use short sentences and concrete nouns.
- Name a concept only *after* the learner has experienced it.
- **Struggle first, then teach.** Every concept block opens with a short problem the learner attempts before the concept is named ("Here is a company where fixing one problem keeps creating another. Figure out why."). Then a 2–3 minute explanation, then transfer. No long text or video before the first interaction.
- Tone stays calm and adult: no confetti, no kids' tone, no "streak" or guilt language. Never claim or imply employment, placement or "job-ready".
- IN content uses ₹, lakh/crore and Indian English. GLOBAL content uses USD and neutral English.

## 2. Length limits (learner-facing)

| Element | Limit |
|---|---|
| Situation | ≤ 120 words |
| Reveal (concept explanation) | ≤ 150 words |
| Quiz stem | ≤ 60 words |
| Option | ≤ 25 words |
| Option feedback | ≤ 40 words |
| Any single screen | ≈ 200 words |
| Inbox brief | ≤ 80 words |
| Stakeholder question / answer | ≤ 20 / ≤ 60 words |
| Opponent challenge / escalation / concession | ≤ 40 / ≤ 40 / ≤ 30 words |
| Hint (each level) | ≤ 40 words |
| Interview model answer | ≤ 150 words |

## 3. Depth Ladder

| Depth | Name | Learner does |
|---|---|---|
| D1 | Recognize | Spots the concept in a situation |
| D2 | Apply | Uses it on a new situation |
| D3 | Analyze | Compares plausible options, finds flaws, notices what's missing |
| D4 | Judge | Decides under ambiguity, weighs trade-offs, states confidence |

Depth range by stage:

| Stage | Concept checks | Cases |
|---|---|---|
| Understand (M1–M2) | D1–D3 | D3 |
| Investigate (M3–M6) | D1–D3 | D3 |
| Decide (M7–M8) | D2–D4 | D4 |
| Deliver (M9–M10) | D3–D4 | D4 |
| Specialist | D2–D4 | D4 |

**Concept Check rule:**
- 3–5 items per concept block.
- The first item sits at the stage's floor; each item is the same depth as the previous one or deeper.
- At least one item reaches the stage's ceiling.
- Every block ends with an ungraded **Go Deeper** question ("why?", "so what?", "what if the opposite were true?", "who would disagree?").

## 4. Quiz item types

| Code | Type | Description |
|---|---|---|
| SCN | Scenario choice | Pick the best interpretation or action in a situation |
| SPOT | Spot the flaw | Find the error in reasoning, a plan or data |
| ASK | Best next question | Choose or write the question that most reduces uncertainty |
| SORT | Categorize | e.g., fact vs assumption |
| RANK | Order | Prioritize or sequence |
| EST | Estimate | Numeric answer as a range; graded on approach and range |
| FIX | Short written answer | 1–4 sentences, graded against explicit criteria |
| AUDIT | AI audit | A short AI-written answer with 1–3 planted flaws; the learner finds and explains them |

**Rules:**
- **Confidence on every item.** Learners rate 50/70/90% before seeing the result.
- **Every wrong option has an Error Library tag,** and its feedback names the error and why it's tempting.
- **Plausible distractors only.** No joke options. Vary the correct option's position; no "all of the above".
- **Written items required:** at least one FIX, ASK or EST item per concept block at D2+.
- **At least one AUDIT item per module.**

## 5. Error Library

| Tag | Error | Tag | Error |
|---|---|---|---|
| E01 | Jumping to solution | E11 | Averages hide the story |
| E02 | Symptom as problem | E12 | Local optimization |
| E03 | Request as problem | E13 | Ignoring second-order effects |
| E04 | Assumption as fact | E14 | Ignoring incentives |
| E05 | Missing comparison / baseline | E15 | Overconfidence |
| E06 | Vague or runaway scope | E16 | Framework as ritual |
| E07 | Correlation as causation | E17 | Leading question |
| E08 | Ignoring base rates | E18 | Weak source trusted |
| E09 | Confirmation seeking | E19 | Sunk-cost reasoning |
| E10 | Anchoring | E20 | Automation bias (trusting AI/tools blindly) |

New tags may be added (E21+). Record any additions in the Module Report.

## 6. Cases & the Company Universe
- **Launch tracks are BA, DA, PM, PD.** Do not write SC or SD cases.
- **Use Universe companies only** (`content/universe/`). Respect their canon facts. A track capstone may add a new company; if so, write its profile first using template T5.
- **Alternate IN and GLOBAL** across core modules. Each track's cases must include at least one of each.
- **Numbers must reconcile.** Every case includes a hidden Consistency Check.
- **Realism:**
  - Stage 1–2 cases include noise and missing data.
  - Stage 3+ cases also include red herrings and conflicting stakeholder views.
- **No real companies** with invented data. **No stereotypes.**
- **Mark real-world claims `[VERIFY]`.**

## 7. Student vs Professional variants

| | Student | Professional |
|---|---|---|
| Prompt | Clear task, defined scope | Vague manager message |
| Data | Provided up front | Provided only when the learner asks for specific exhibits |
| Scaffolding | Hint ladder L1–L5 on request (T4) | No hints; stakeholder menu and data room instead |

## 8. Self-Review Checklist
Run on every file. Record the results in the Module Report.

1. Every concept opens with a situation, not a definition.
2. Only owned concepts are taught; earlier ones are applied.
3. Length limits met.
4. Depth ladder respected for the stage.
5. Every wrong option has an error tag and feedback.
6. At least one FIX/ASK/EST item per block at D2+; at least one AUDIT item per module.
7. Go Deeper question present in every block.
8. Universe canon respected; IN/GLOBAL mix met.
9. Numbers reconcile (Consistency Check shown).
10. `[VERIFY]` marks present on real-world claims.
11. Model answers show reasoning and allow multiple defensible conclusions.
12. Both case variants present.
13. Every case has a stakeholder menu (mixed useful/irrelevant/leading), an Opponent script (checklist, escalation, concession), a hint ladder L1–L5 and a self-review checklist, all using only canon and case facts.
14. Hints and Opponent text never give the answer or write the learner's structure.
15. No job-ready or placement claims; no streak language.
